# What is MultiUp Direct?

MultiUp Direct is an application written in Rust that extracts direct
links from [MultiUp](https://multiup.io/) and [Mirrored](https://www.mirrored.to/) and allows for the unlocking of these
links with a Debrid service.

## Features

* Convert bulk short and long links into direct links, with support for MultiUp projects and password protected links.
* Built-in Debrid service support for [AllDebrid](https://alldebrid.com/) and [Real-Debrid](https://real-debrid.com/).
